End-to-End Testing Guide

Tipster posts a verified booking-code slip → customer buys it over Mobile Money → admin reviews. Follow the steps in order.

Mobile-first PWA App: https://betfluencer.apps.katumbapaul.com Pay-per-slip · UGX ~10 min
Before you start. Make sure all three services are running: the web app (betfluencer.apps.katumbapaul.com), the bet-code worker (verifies booking codes), and ideally the sync poller. Payments run in ioTec demo mode when no live ioTec keys are set — the MoMo charge auto-succeeds with no real money moving. With live keys, an STK push is sent to the phone and must be approved on the handset.

Verification takes time. Loading a code on a live bookie takes a few seconds to ~2 minutes. If a slip is stuck on ⏳ Verifying…, the worker may be down or the code expired — the sync poller re-checks pending coded slips on its interval.
Slips disappear from the marketplace when expired. Once a slip's earliest match has kicked off by more than 90 minutes, it drops off the customer marketplace and tipster channels (no longer buyable). The owning tipster still sees it on their own dashboard, tagged Expired.
Payments. In demo mode (no ioTec keys) the MoMo charge auto-resolves to success — ideal for testing the unlock + payout flow without real money. In live mode, the buyer approves an STK push on the phone; the webhook (or status poll) confirms before the slip unlocks and the tipster is paid.
